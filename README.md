# PPD Digitalization Dashboard

Interactive UIUX prototype for the PPD (Project Planning & Development) digitalization initiative —
covering the **Master KM**, **Master Infra**, and **Local Infra** submission tracking dashboards.

Built as a single self-contained HTML file (no server or build step). Open `index.html` in any browser.

## What it shows
- Left "OPERATION" sidebar with Region › BU › Project navigation
- Process tabs, with Master KM / Master Infra / Local Infra as live dashboards
- Milestone-progress gauges, status KPI cards
- Dot-timeline milestone tracker (green = completed, amber = in progress/ulasan, orange = submitted & pending, red = delayed, grey = default, blue = appeal)
- Click any milestone dot to drill in: step actions, department clearance grid, document checklist, and manual "ping consultant" button

> Prototype with sample data (Utopia South). For demonstration of the flow and interface concept.
